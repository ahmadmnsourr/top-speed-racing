# Top Speed Racing — v1.0.0 (Windows x64)

First playable Windows release of **Top Speed Racing**, a 2D arcade game written in C# using Windows Forms.

## Features
- Classic Mode and Power-Up Rush
- Four selectable environments: Field, Desert, Highway and Snow
- Dynamic traffic, collision detection, sound effects and in-game scoring
- Nitro, shield and weapon power-ups
- Pause, restart, control guide and game-over screens

## Install and play
1. Download `Top-Speed-Racing-v1.0.0-Windows-x64.zip` from the Assets section.
2. Extract **all** files into a folder on a Windows x64 computer.
3. Double-click `TopSpeedRacing.exe`.
4. Press Enter, select the map and game mode, and play.

No Visual Studio or separate .NET installation is required for the supplied self-contained build. Keep the executable, Images, Audios and runtime files together. Windows may show an unsigned application warning.

## Notes
- Built and launched successfully on the developer's Windows PC; not independently verified on other machines.
- High-score persistence may reset when closing the game.
- Game assets include third-party material originally obtained from free-to-use sources; precise licenses and attribution requirements remain to be confirmed. See `ASSET_PROVENANCE.md` in the source repository.
