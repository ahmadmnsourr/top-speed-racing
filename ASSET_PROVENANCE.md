# Asset origins, attribution and licensing

Top Speed Racing was created as a personal C# / Windows Forms game project. The developer reports downloading a number of the game graphics and audio from sources described as open-source or free-to-use. The precise websites, individual licenses and creator credits are not currently documented. **This report is not independent confirmation that every asset can be redistributed.**

## Included media inventory

- `TSR/Images/`: 41 images (vehicles, gameplay scenery, UI, backgrounds and visual effects).
- `TSR/Audios/`: 8 audio files used by the game.
- `screenshots/`: 9 screenshots captured from the game.
- `media/gameplay-demo.mp4`: approximately 41-second edited, muted gameplay demonstration.
